# openspec/changes/archive/ — completed changes

`/opsx:archive` moves a change folder here once its delta has been merged into
`openspec/specs/`. Archived folders are history: they record what a change proposed and how
it was decomposed, not what is true now. Read `openspec/specs/` for that.

`openspec validate --archived` asserts every `tasks.md` checkbox in here is ticked; CI runs it.
